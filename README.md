# 🧠 Analyst – Neo4j Graph Explorer for Restaurants and Reviews

Cette application **Streamlit** connectée à **Neo4j** permet d’explorer de façon interactive les relations entre les **utilisateurs**, leurs **avis** et les **restaurants**, à partir des données du **Yelp Challenge**.

Elle s’appuie sur un **modèle de graphe enrichi**, pour une analyse fine et visuelle.

---

## 🚀 Fonctionnalités principales

- 🔎 **Recherche** par nom de restaurant ou ID utilisateur  
- 📊 **Tableau** des restaurants les mieux notés  
- 👥 **Liste** des utilisateurs les plus actifs  
- 🧩 **Visualisation** des liens entre utilisateurs, avis et restaurants  
- 🎯 **Filtres dynamiques** : ville, score minimal, catégories…

---

## 🧰 Technologies utilisées

- **Streamlit** : interface web interactive  
- **Neo4j** : base de données orientée graphe  
- **pandas** : traitement et filtrage des données  
- **pyvis / networkx** : visualisation des graphes  
- **neo4j-driver** : connexion Python ↔ Neo4j
